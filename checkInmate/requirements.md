Final Project
Your final project is a meant to demonstrate everything you have learned during this course. 21 weeks ago, you started your journey toward being a software developer and this project is your final milestone.

Your Capstone / Final Project is Due by Noon on August 14th, 2026.
For your final project, you will submit a GitHub repository that contains at least three different projects:

A C# web API using controllers or minimal API.
A project that consumes that API. This can be a C# console application or a web site that uses JavaScript to work with the API, or it can be a web site that uses any of the various JavaScript frameworks to create web sites such as Angular, React, or Vue.
A test project - automated testing to prove that your code works.
This is a chance to bring in everything you have learned about software development whether you learned it at Code:You or somewhere else. Your final project also serves as a potential portfolio item for prospective employers. Your app can do anything - as long as it meets these basic requirements:

Submitted as a single GitHub repository,
The solution builds successfully,
Uses ASP.NET and C# to expose a web API,
A project exists that uses those web APIs to create, read, update, and delete data stored in-memory,
Automated testing has been written,
Automated tests pass and cover a significant portion of possible execution paths.
Your project is documented in a README.md file that contains, at bare minimum:
Your app's name and intended purpose,
How to build and run your application,
What did you learn from this project/course?,
If you had more time, what would you have done differently or what additional features would you have added?
