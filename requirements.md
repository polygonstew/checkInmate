## Project Overview
This final project is the culminating milestone of a 21-week software development journey. It serves as a comprehensive demonstration of acquired skills and functions as a portfolio centerpiece for prospective employers.

## Core Deliverables
The project must be submitted as a single GitHub repository containing at least three distinct projects:

1. **The Backend Web API**
   * Must be built using C# and ASP.NET.
   * Can utilize either Controller-based architecture or Minimal APIs.
   * Must expose endpoints to Create, Read, Update, and Delete (CRUD) data.
   * Data must be stored in-memory.

2. **The Consumer Application**
   * A project that directly interacts with and consumes the C# Web API.
   * Supported formats include:
     * A C# Console Application.
     * A vanilla JavaScript website.
     * A frontend framework application (e.g., Angular, React, Vue).

3. **The Testing Suite**
   * An automated testing project.
   * Must prove the code functions correctly.
   * Tests must pass and cover a significant portion of possible execution paths.

## Technical Requirements Checklist
* [ ] Submitted as a single GitHub repository.
* [ ] The solution builds successfully without errors.
* [ ] Uses ASP.NET and C# to expose a web API.
* [ ] Contains a consumer project handling CRUD operations.
* [ ] Uses in-memory data storage.
* [ ] Includes automated testing.
* [ ] Automated tests pass and demonstrate substantial code coverage.

## Documentation (README.md)
The repository must include a well-structured README.md file containing at bare minimum:
* Project Identity: The application's name and its intended purpose.
* Setup Instructions: Clear steps on how to build and run the application locally.
* Retrospective: A reflection on what was learned from this project and the course overall.
* Future Roadmap: A discussion of what would be done differently or what additional features would be added with more time.
